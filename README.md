# C.R.A.V.E — Cycling & Local Discovery App 🚴‍♂️🍽️

C.R.A.V.E is a mobile cycling application that enhances urban cycling through **real-time navigation, local discovery, activity tracking, and gamification**. The project focuses on usability, engagement, and iterative design driven by user feedback.

---

## 🛠️ Tech Stack

- React Native (Mobile App Development)
- Google Maps API (Real-time navigation & mapping)
- Figma (UI/UX design & prototyping)

---

## 📌 Key Features

### 🚴 Route Planning
- Search destinations such as restaurants, cafés, and parks
- Receive suggested cycling routes based on **distance, safety, and scenery**
- Interactive map-based route selection

### 📍 Live Ride Tracking
- Start/stop cycling sessions
- Real-time GPS tracking using Google Maps API
- Tracks distance and duration automatically

### 🍽️ Local Discovery
- Discover nearby points of interest along routes
- Filter restaurants, cafés, breweries, and parks
- View location details before visiting

### 🏅 Gamification System
- Log visited locations during rides
- Earn badges and achievements based on activity
- “Food Counter” tracks exploration progress

### 📊 Leaderboards
- Monthly ranking system based on:
  - Distance cycled
  - Locations visited
- Competitive and social engagement features
- Incentive system to encourage consistent usage

---

## 🧪 User-Centered Design & Iteration

The app was refined through **two rounds of user testing**, leading to iterative improvements:

### Iteration 1 Improvements
- Improved search bar usability and layout
- Added safety warnings before ride start
- Fixed unit inconsistencies (km vs km/h)
- Introduced leaderboard incentives
- Improved UI spacing and clarity

### Iteration 2 Improvements
- Enhanced rating system after location visits
- Added safety prompts during route selection
- Improved news feed layout and structure
- Added cost estimation for route planning
- Simplified route setup UI

## 🔐 Safety Features
